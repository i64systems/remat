5. THE RESUME STORY (determinism claim under preemption, frozen)
================================================================
The funded run is a SEGMENT CHAIN: every checkpoint banks a digest and
a full sidecar (optimizer + RNG + step). G1-CARD limb (ii) PROVES
resume-exactness at a real boundary: a resumed segment produces the
same bytes as the straight run. Therefore a preempted or crashed run
that resumes from its last banked checkpoint carries the SAME
whole-run determinism claim: the final bytes are a pure function of
(code, data pin, seeds), independent of the preemption pattern. If a
sidecar is missing or corrupt (crash mid-write), resume falls back to
the previous complete checkpoint pair; if full state restoration is
ever impossible, the claim NARROWS honestly to per-segment determinism
and the receipt says so in those words. (Note: after init the trainer
consumes no RNG - data order is precomputed, no dropout - so the RNG
sidecar is belt-and-braces, saved anyway.)
